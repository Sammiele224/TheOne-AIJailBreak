# Environment Variables

| Variable            | Purpose                            | Example                             |
| ------------------- | ---------------------------------- | ----------------------------------- |
| `API_KEY`           | Shared secret for protected routes | `change-me`                         |
| `ALLOWED_ORIGINS`   | Comma-separated allowed origins    | `http://localhost:5173`             |
| `DATABASE_URL`      | Database connection string         | `sqlite:////app/data/neurocorp.db`  |
| `DEBUG`             | Enables debug behavior             | `false`                             |
| `GROQ_API_KEY`      | Groq provider key                  | `gsk_...`                           |
| `OPENAI_API_KEY`    | OpenAI provider key                | `sk-...`                            |
| `DEEPSEEK_API_KEY`  | DeepSeek provider key              | `...`                               |
| `ANTHROPIC_API_KEY` | Anthropic provider key             | `...`                               |
| `VITE_API_BASE_URL` | Frontend API base URL              | `http://localhost:8000/api/v1/game` |
| `VITE_API_KEY`      | Frontend API key if required       | `change-me`                         |
